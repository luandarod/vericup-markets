# Roteiro de demo em cinco minutos

- 0:00-0:30: o problema de confiar em um backend para encerrar mercados.
- 0:30-1:15: registrar Brasil, Empate ou adversario com PLAY virtual, sem carteira.
- 1:15-3:45: SSE final, lock, prova `statKeys=1,2`, CPI TxLINE e outcome derivado.
- 3:45-4:30: abrir receipt demo, proof hash e ambiente de validacao.
- 4:30-4:50: mostrar 12 testes Anchor e cobertura TypeScript.
- 4:50-5:00: feedback: uma API de fixtures com filtro de competicao simplificaria demos de torneio.

Use replay historico somente com o rotulo REPLAY. Ele precisa solicitar a prova real da mesma fixture e sequencia e percorrer a mesma transacao de resolucao.

Observacao: o torcedor nao conecta carteira. A carteira Solana fica apenas no lado operacional para ativar a API TxLINE e, quando desejado, publicar ou executar a prova on-chain.
